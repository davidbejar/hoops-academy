Global rate limits (ADR-0033): Envoy Gateway must run its rate limit service with a Redis backend, otherwise the
rate-limit BackendTrafficPolicies are not applied. Envoy Gateway Helm values (cluster operator):
  config.envoyGateway.rateLimit.backend.type=Redis
{{- if .Values.rateLimit.redis.enabled }}
  config.envoyGateway.rateLimit.backend.redis.url=ratelimit-redis.{{ .Release.Namespace }}.svc.cluster.local:6379   (Redis of this release)
{{- else if .Values.rateLimit.redis.url }}
  config.envoyGateway.rateLimit.backend.redis.url={{ .Values.rateLimit.redis.url }}   (external Redis)
{{- else }}
  config.envoyGateway.rateLimit.backend.redis.url=<host:port>   (rateLimit.redis.url is not set: name your Redis there)
{{- end }}
  config.envoyGateway.rateLimit.failClosed=false   (fail open when Redis is unreachable; see ADR-0033)
  config.envoyGateway.rateLimit.timeout=100ms
{{- if .Values.rateLimit.redis.enabled }}
  config.envoyGateway.provider.kubernetes.rateLimitDeployment.container.env=
    [{name: REDIS_AUTH, valueFrom: {secretKeyRef: {name: envoy-ratelimit-redis-auth, key: auth}}}]
Redis ACL (WP46): the Redis of this release accepts only user {{ .Values.rateLimit.redis.acl.user }} (password: key {{ .Values.rateLimit.redis.acl.passwordSecret.key }} of Secret
{{ .Values.rateLimit.redis.acl.passwordSecret.name }} in {{ .Release.Namespace }}). Secret envoy-ratelimit-redis-auth in envoy-gateway-system holds auth=<user>:<password>
for the rate limit pods. Both Secrets exist before the install (docs/runbooks/release.md section 4).
{{- end }}
