# Work packages

One file per work package, `WP<n>-<slug>.md`: the brief the package was started from and, once it was done, a
`## Handover` section with what was built, how it was verified and the open points. The cross-cutting backlog, the
product owner's numbered decisions and the plan of each round are in [FOLLOW-UPS.md](FOLLOW-UPS.md).
