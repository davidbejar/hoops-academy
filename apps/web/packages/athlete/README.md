# hoops_athlete_api (EXPERIMENTAL)
Training & attendance, athlete health & fitness.

Authorization (docs/domain/authz-matrix.md): ADMIN and team staff (COACH / ASSISTANT_COACH) write training data,
attendance, injuries, body measurements and test results; PARENT reads and may write injuries, body measurements,
planned absences and plan completions for linked players; PLAYER reads own data and may write own planned absences
and plan completions. Player names are not stored here: clients join ids with core-service rosters.
