# hoops_game_api (EXPERIMENTAL)
Match operations and statistics (offline-first, event-sourced).

Match events are append-only, client-identified facts (`id` = client-generated UUIDv7, unique per
`(matchId, deviceId, clientSeq)`). The server validates **schema + authorization only**, never domain consistency:
an impossible substitution becomes a projection *warning* that staff fix with a VOID event. Box scores and season
statistics are projections re-computed on every accepted batch.

`MatchEvent` mirrors `events/match-event.schema.json` (JSON Schema 2020-12); `MatchEventSchemaConsistencyTest`
keeps both in sync.

Authorization (docs/domain/authz-matrix.md): team staff (COACH / ASSISTANT_COACH) and ADMIN may run matches and
enter any event; PARENT may enter player-attributed stat events for linked players and VOID their own events only;
PLAYER is read-only (own statistics).
